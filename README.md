# 🏠 2026년 2차 서울시 청년안심주택(공공임대) 청약 도우미

66페이지 분량의 입주자모집공고문을 직접 읽지 않아도, **자연어 질문 한 번**으로 일정·자격·임대조건·서류·가점 등 원하는 정보를 찾아주는 **RAG + Text2SQL 기반 챗봇**입니다.

공고문 본문은 벡터 검색(RAG)으로, 단지별 임대조건·자격요건 표 같은 정형 데이터는 Text2SQL로 조회한 뒤 LangGraph 워크플로가 자동으로 라우팅하여 답변을 생성합니다. 모든 답변에는 근거가 된 공고문 페이지 또는 실행된 SQL이 함께 제시됩니다.

## ✨ 핵심 기능

- **청약 일정 및 자격 안내**: 접수 일정, 계층별(청년/신혼부부) 신청 자격 및 순위 확인
- **단지별 임대조건 조회**: 단지명·평형별 보증금, 계약금, 잔금, 월 임대료 확인
- **가점 및 서류 안내**: 서울 거주 기간, 청약통장 납입 횟수 기반 가점 계산 및 순위별 제출 서류 안내
- **근거 기반 답변**: 답변마다 참고한 공고문 페이지 번호와 카테고리, 또는 실행된 SQL을 함께 제시
- **실시간 스트리밍**: LangGraph가 거쳐 가는 노드(의도 분류 → 벡터 검색/DB 조회 → 답변 생성)를 진행 중에 표시
- **멀티턴 대화**: 이전 대화 맥락을 함께 전송해 "그럼 보증금은?" 같은 후속 질문 처리

## 🧱 기술 스택 및 구조

- **AI/오케스트레이션**: LangChain, LangGraph
- **벡터 검색**: Qdrant Cloud (`text-embedding-3-small`)
- **정형 데이터 조회**: Text2SQL, Supabase(PostgreSQL)
- **백엔드**: FastAPI, SSE 스트리밍
- **프론트엔드**: React (Vite) + Tailwind CSS
- **배포**: Docker, Render

---

## 🚀 실행 방법

```bash
# 1) 환경 변수 설정
cp .env.example .env   # OPENAI_API_KEY, QDRANT_URL, QDRANT_API_KEY, SUPABASE_DB_URL 입력

# 2) 의존성 설치
uv sync
cd web && npm install && cd ..

# 3) API 서버
uv run uvicorn api.main:app --app-dir src --reload --port 8000

# 4) 웹 프론트엔드 (새 터미널)
cd web && npm run dev
```

브라우저에서 `http://localhost:5173` 접속.
